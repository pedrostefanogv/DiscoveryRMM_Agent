Notificacao Visual Nativa PSADT

      
Executa cmdlets PSADT reais: Show-ADTBalloonTip, Show-ADTInstallationPrompt, Show-ADTInstallationProgress, Show-ADTDialogBox, Show-ADTInstallationRestartPrompt e Show-ADTInstallationWelcome. Timeouts de prompt/dialog limitados a 3300s (UI.DefaultTimeout do config.psd1). Personalize o logo/banner/acento dos dialogs Fluent via campos Branding (o PSADT exibe o logo default do toolkit quando vazio). Dica: passe o mouse sobre um campo (ou foque nele via Tab) para ver a ajuda do que ele faz.

      

      

        

          
          
          Define o cmdlet PSADT executado. Os campos abaixo aparecem/desaparecem conforme o tipo: so ficam visiveis os campos que o cmdlet realmente usa.
        

        

          
          
          Titulo exibido na janela/balao: -BalloonTipTitle (Balloon), -Title (Prompt) e no Dialog Box. Nao se aplica a Progress, Restart Prompt e Welcome (usam textos padrao do toolkit), por isso o campo some nesses tipos.
        

        

          
          
          Nome do app passado ao Open-ADTSession -AppName; aparece na marcacao dos dialogs do PSADT. Nao se aplica ao Dialog Box (Win32), que roda sem sessao PSADT.
        

        

          
          
          Somente Progress Bar: por quantos segundos a janela de progresso fica visivel antes de Close-ADTInstallationProgress fechar (1–60s).
        

        

          
          
          Linha secundaria: -Subtitle no Prompt e -StatusMessageDetail na Progress Bar. Vazio = omitida. Balloon, Dialog Box, Restart e Welcome nao usam subtitulo.
        

        

          
          
          Texto principal ao usuario: -BalloonTipText (Balloon), -Message (Prompt), -StatusMessage (Progress) e -Text (Dialog Box). Restart Prompt e Welcome usam as mensagens padrao do PSADT, entao o campo some nesses tipos.
        

        

          
          
          Somente Balloon: tempo (1–120s) em que o balloon fica visivel; vira -BalloonTipTime em milissegundos. Default do PSADT: 10s.
        

        

          
          Somente Balloon: -NoWait cria o balloon em thread assincrona — o script nao espera o balloon sumir (teste mais rapido, sem resposta de usuario).
        

        

          
          
          -ButtonLeftText do Prompt. Sobrescreve o botao padrao do tipo (ex.: "Sim" no Sim/Nao, "Continuar" no Continuar/Adiar). Vazio = mantem o padrao do PSADT.
        

        

          
          
          -ButtonMiddleText do Prompt: adiciona um botao central a mais. Vazio = o botao do meio nao existe.
        

        

          
          
          -ButtonRightText do Prompt. Sobrescreve o padrao ("OK", "Nao", "Adiar"). No prompt de entrada (prompt_input) e o botao que submete o texto digitado.
        

        

          
          
          Somente prompt_input: pre-preenche a caixa de texto via -DefaultValue. O que o usuario digitar (ou deixar) volta em "Resposta do usuario".
        

        

          
          
          Somente Prompts: -Icon do dialogo (enum DialogSystemIcon). Ex.: Question para confirmacoes, Shield para acoes que exigem admin. Vazio = padrao do PSADT.
        

        

          
          
          Somente Prompts: -Timeout em segundos ate o dialogo fechar sozinho (0 = usa 120s no teste; max 3300s = UI.DefaultTimeout do config.psd1). Com NoWait marcado, o timeout e ignorado.
        

        

          
          
          Somente Prompts: NoWait (-NoWait) roda o dialogo em thread assincrona, sem esperar resposta; NotTopMost (-NotTopMost) deixa a janela sem ficar acima de todas as outras.
        

        

          
          
          Somente Restart Prompt: -CountdownSeconds da contagem regressiva ate o restart forcado (5–3600s). Desativado quando "sem countdown" esta marcado.
        

        

          
          Somente Restart Prompt: -NoCountdown exibe a janela sem contagem regressiva — o usuario apenas decide se reinicia agora.
        

        

          
          
          Somente Welcome: -CloseProcesses, nomes de processos separados por virgula (ex.: winword,excel). Se algum estiver aberto, o PSADT avisa/oferece fechar antes de instalar.
        

        

          
          
          Somente Welcome: -DeferTimes, quantas vezes o usuario pode adiar a instalacao (0 = adia indefinidamente enquanto Allow Defer estiver ativo). Ignorado se Allow Defer estiver desmarcado.
        

        

          
          
          Somente Welcome: -DeferDeadline, data limite (yyyy-MM-dd) depois da qual o usuario nao pode mais adiar. Vazio = sem data limite.
        

        

          
          
          Somente Welcome: -CloseProcessesCountdown, fecha os processos listados automaticamente apos N segundos sem resposta (0 = esperar para sempre).
        

        

          
          
          Somente Welcome: Allow Defer (-AllowDefer) mostra o botao Adiar; Block Execution (-BlockExecution) impede que o usuario abra os processos listados enquanto o deploy roda.
        

        

          
          
          Branding dos dialogs Fluent (Prompts, Progress, Restart, Welcome): caminho do logo PNG/.ICO. Vazio = usa o icon.ico do Discovery Agent. Balloon e Dialog Box (Win32) usam icones de sistema e ignoram isso.
        

        

          
          
          Logo usado quando o Windows esta em modo escuro. Vazio = usa o mesmo logo do modo claro/default.
        

        

          
          
          Banner (faixa superior) exibido apenas nos dialogs em estilo Classic. Nao afeta Fluent nem Dialog Box Win32.
        

        

          
          
          Estilo visual dos dialogs do PSADT: Fluent (moderno, WPF) ou Classic (WinForms 3.x, usa o banner). Vazio = Fluent.
        

        

          
          
          Cor de acento dos dialogs Fluent (hex RGB ou ARGB, ex.: 4A9EFF ou FF4A9EFF). Vazio = cor default do toolkit. Somente dialogs Fluent (nao afeta Balloon/Dialog Box).
        

        

          
          
          Somente Dialog Box: conjunto de botões do MessageBox (-Buttons). O texto do botão clicado volta em "Resposta do usuario".
        

        

          
          
          Somente Dialog Box: -DefaultButton, qual botao comeca focado (respeitando a quantidade de botões escolhida acima).
        

        

          
          
          Somente Dialog Box: -Icon do MessageBox Win32 (None/Stop/Question/Exclamation/Information). Enum diferente do icon do Prompt.
        

        

          
          
          Somente Dialog Box: -Timeout em segundos (0 = 120s no teste; max 3300s = UI.DefaultTimeout). Com NoWait marcado, o script nao espera o dialogo.
        

        

          
          
          
          
          Somente Dialog Box: NoWait (-NoWait) assincrono; ExitOnTimeout (-ExitOnTimeout) encerra o script ao expirar; NotTopMost (-NotTopMost) sem ficar acima de tudo; Force (-Force) exibe mesmo com DeployMode Silent/NonInteractive.
